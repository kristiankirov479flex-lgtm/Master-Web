# Master-Web

Kristian's sales front page (`index.html`) and every showcase and template site it links to.
All sites are static HTML, CSS and vanilla JavaScript. Every site has a Bulgarian page (`/`) and an English page (`/en/`),
a mock-backend request system (demo mode: nothing is sent), a demo back office (`admin.html`), privacy pages,
five colour schemes on a bottom dock and no third-party requests (the map loads only after a click).

## Working on a site

Most sites are generated by Python. From inside a site folder:

```bash
python tools/build_pages.py && python tools/build_privacy.py
```

Edit the values at the top of `tools/build_pages.py` (services, prices, hours, texts), not the generated HTML.
`SKILL.md` describes the whole method, the design rules and the lessons learned.

## Adding a site to the front page

1. Add the folder to the `PROJECTS` array in `index.html` (a new type or a new design in an existing type).
2. Add its two pages to `sitemap.xml`.
3. The design count, the tabs and the form's list of business types are generated from `PROJECTS`.
   The text in the meta description and in the "kinds of business" fact is written by hand: update it (Bulgarian and English).

## The front page hero

The hero shows a live preview of one demo on a desktop frame and a phone frame (currently `Physio_1`, Motus). To change it, edit the `src`, link
and caption of the `.stage` block in `index.html` and the `stage.*` and `float.*` texts (Bulgarian in the HTML, English in the `EN` object;
`stage.src` is the English page). The chips under the hero text are generated from `PROJECTS`.

## Local preview

Serve this folder on any static server (for example `python -m http.server 5180`) and open `http://localhost:5180/`.
All demos share one origin, so they share localStorage; every site uses its own key prefix.

## Before going live

Replace `https://YOUR-DOMAIN` in `sitemap.xml` and `robots.txt`, add canonical and hreflang links, fill in the yellow fields on the privacy pages
and replace all example names, prices, photos and contacts. See each site's `TODO.md`.
