# Images

Drop photos here with these names. Any file that is missing is simply skipped,
so you can add them one at a time. Use `.jpg`, about 1600 px on the long side,
under ~300 KB each (compress with squoosh.app or similar).

| File | Where it appears |
| --- | --- |
| `hero.jpg` | Full-screen photo at the top (replaces the mountain drawing). Landscape, the view works best. |
| `room-1.jpg` (large), `room-2.jpg`, `room-3.jpg` | "The room" section: room, balcony, living room |
| `kitchen-1.jpg` (large), `kitchen-2.jpg`, `kitchen-3.jpg` | "Kitchen in the yard" section: kitchen, yard, dinner outside |
| `gallery/01.jpg` … `gallery/10.jpg` | Gallery. 01 and 06 are shown large. Order: view, village, forest, room, balcony, living room, kitchen, yard, evening, dinner |
| `places/<id>.jpg` | Optional photo on each "Nearby" card. Ids: `trigradsko-zhdrelo`, `dyavolskoto-garlo`, `yagodinska-peshtera`, `buynovsko-zhdrelo`, `shiroka-laka`, `devin`, `samodivsko-praskalo`, `yagodina`, `trigrad`, `muzey-devin` |
| `og.jpg` | 1200×630 preview image for Facebook/Viber links (see the comment in `index.html`) |

Captions and alt text are already written in both languages (`js/i18n.js`).
